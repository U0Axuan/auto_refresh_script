# 手动测试清单（v2.0.0）

每次发版前**必须**全部通过。

## 环境
- [ ] 浏览器：Chrome（最新稳定版）
- [ ] 浏览器：Firefox（最新稳定版）
- [ ] 脚本管理器：Violentmonkey
- [ ] 脚本管理器：Tampermonkey（兼容性验证）

## 1. 安装与启动
- [ ] 1.1 从 `auto_refresh_script.user.js` 链接安装，脚本管理器弹出确认
- [ ] 1.2 安装完成后，**任何页面**都不应自动出现主面板
- [ ] 1.3 页面右下角出现紫色圆形浮动按钮
- [ ] 1.4 点击浮动按钮 → 主面板出现，按钮消失
- [ ] 1.5 刷新页面 → 主面板自动出现（因为 isEnabled 已为 true）
- [ ] 1.6 卸载并重新安装 → 默认回到浮动按钮状态

## 2. 基础功能
- [ ] 2.1 切换主开关为 ON → 状态变为"运行中"
- [ ] 2.2 倒计时进度条平滑增长（肉眼观察无明显跳变）
- [ ] 2.3 到点后页面刷新，计数 +1
- [ ] 2.4 设置 `最大运行次数=3`，到 3 次后自动停止
- [ ] 2.5 点击重置 → 停止 + 计数清零

## 3. 配置
- [ ] 3.1 修改 `刷新间隔` 为 1 秒 → 立即生效（下次刷新按新间隔）
- [ ] 3.2 修改 `刷新间隔` 为 3600 秒 → 接受
- [ ] 3.3 尝试输入 0 或 -1 → 应被 clamp 到 1
- [ ] 3.4 尝试输入 99999 → 应被 clamp 到 3600
- [ ] 3.5 切换 `目标标签页` 单选 → 选中态正确
- [ ] 3.6 关闭脚本 → 重新启用 → 配置保留

## 4. 拖拽 & 最小化
- [ ] 4.1 鼠标按下标题栏并拖动 → 面板跟随移动
- [ ] 4.2 拖到屏幕边缘 → 不超出视口
- [ ] 4.3 点击 `[-]` 按钮 → 面板缩为 56×56 圆角
- [ ] 4.4 再次点击 → 恢复
- [ ] 4.5 拖拽最小化状态的面板 → 仍可拖动
- [ ] 4.6 触屏拖拽（用 DevTools 模拟）→ 同样工作

## 5. 快捷键
- [ ] 5.1 在非输入框聚焦时按 `Alt+R` → 切换 start/stop
- [ ] 5.2 在 `<input>` 中按 `Alt+R` → 不应触发（避免干扰输入）
- [ ] 5.3 旧的 `Ctrl+Shift+R` 不应再被脚本拦截（应触发浏览器硬刷新）

## 6. 排除与安全
- [ ] 6.1 访问 `https://accounts.google.com/` → 无浮动按钮（@exclude 生效）
- [ ] 6.2 访问 `https://example.com/login` → 无浮动按钮
- [ ] 6.3 访问 `https://example.com/checkout` → 无浮动按钮
- [ ] 6.4 iframe 内页面（如 YouTube 嵌入）→ 脚本不执行
- [ ] 6.5 DevTools Console 无 error

## 7. 性能
- [ ] 7.1 标签页后台 1 分钟后回到前台 → 进度条应"瞬时"跳到当前位置
- [ ] 7.2 运行 30 分钟无内存泄漏（Chrome Task Manager 观察 JS Heap 平稳）
- [ ] 7.3 多次 start/stop（10 次）→ 无重复面板

## 8. a11y
- [ ] 8.1 键盘 Tab 可以在所有控件间循环
- [ ] 8.2 屏幕阅读器（VoiceOver / NVDA）可朗读"状态：运行中"
- [ ] 8.3 系统开启"减少动效" → 进度条不再平滑（直接跳）
- [ ] 8.4 按钮聚焦时显示 outline

## 9. 调试
- [ ] 9.1 访问 `?refreshDebug=1` 页面 → Console 输出 `[AutoRefresh v2.0.0]` 日志
- [ ] 9.2 正常页面 → 无 log（仅 warn/error）
